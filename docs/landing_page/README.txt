PROJETO RECARGA FÁCIL

Estrutura dos arquivos:

recarga-facil-projeto/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/

Como abrir:
1. Extraia o arquivo .zip
2. Abra o arquivo index.html no navegador
3. Para editar o visual, altere css/style.css
4. Para adicionar interações, altere js/script.js

Projeto separado a partir do HTML original enviado.
